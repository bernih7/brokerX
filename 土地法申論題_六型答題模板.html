判型訊號題幹有「委託經紀人出售」「說明書之解說義務」「試就〇〇面向闡述」「應如何向丙解說」

四段骨架

  1. 定義：經紀人以不動產說明書向買方解說的義務（經紀條例§23、§24；居間人據實報告民法§567）
  2. 法條：題目土地涉及的管制條文（都計§17、§50、§51、土徵§4、平均§59、重劃辦法§13…）
  3. 涵攝：每一筆土地或每一個面向一段，段首寫「該地現況＋對買方的影響」，再寫法條要件、套到題目的 X 地／Y 地
  4. 結論：分項列出說明書應載明的事項

寫法重點題目通常有兩筆地或兩個面向（地用、地權），一定要分開寫，並把「對買方權益的影響」寫出來；只背條文不套到 X 地、Y 地會被扣分。

常見失分

  • 只寫法條，沒有套到題目的 X 地、Y 地
  • 漏寫但書（如都計§17Ⅱ「逾二年…或主要公共設施已興建完成」）
  • 說明義務的法源寫錯對象（經紀條例§23 是向相對人解說）

二爭議判斷型「甲之主張有無理由／道理」1官方2預測

判型訊號題幹有「甲不服，主張…」「問甲之主張有無理由」「是否合理」

四段骨架

  1. 定義：先講清楚爭點所在的制度（稅基、查估方式、收回權…）
  2. 法條：雙方主張各自的依據條文
  3. 涵攝：①先寫結論「甲之主張有／無理由」；②法律依據；③套題目事實；④理由。主張型題目用「就情／就理／就法而言」三段論證，最後寫現行可用的救濟
  4. 結論：一句話判斷＋理由，不要比條文說得更滿

寫法重點結論要明確（有理由／無理由／不無道理），但「法無直接明文」不等於「於法無據」，用詞要準。

常見失分

  • 只描述制度，沒有回答「有無理由」
  • 結論說得太滿（例：把「依據薄弱」寫成「於法無據」）
  • 漏寫甲現行可用的救濟

三比較型兩種以上制度逐項比較3官方7預測

判型訊號題幹有「試比較」「有何差異」「何謂A？何謂B？」「區別」

四段骨架

  1. 定義：兩個（或三個）制度各給一句定義
  2. 法條：各自的條號
  3. 涵攝：每段一個比較基準（立法目的／要件／效力／機關／期限…），兩者都要寫到，段首直接寫出差異
  4. 結論：一句話點出最核心的差異（通常是效力）

寫法重點先在草稿列出比較基準再寫；效力欄（物權 vs 債權、相對無效 vs 停止新登記）最容易失分。

常見失分

  • 兩個制度分開各寫一大段，沒有逐項對照
  • 效力性質寫錯（§34-1Ⅳ 債權效力；§104、§107 物權效力）
  • 漏寫其中一方的要件

六程序型公告・通知・期限・異議・救濟3官方3預測

判型訊號題幹有「程序為何」「公告通知事項」「異議之時機與方式」「查定手續」「如何處理」

四段骨架

  1. 定義：程序的目的
  2. 法條：每個程序階段的條文
  3. 涵攝：依時間順序一個階段一段，段首寫「誰、在什麼時點、做什麼」，再寫期限（30日、15日、40日…）與不遵守的效果
  4. 結論：把流程串成一句（公告→異議→調處→裁決）

寫法重點時間軸不能顛倒；每個階段都要寫「期限」和「由誰處理」。

常見失分

  • 把兩個階段混在一起（如重劃計畫書公告與分配結果公告）
  • 期限寫錯
  • 漏寫救濟途徑
