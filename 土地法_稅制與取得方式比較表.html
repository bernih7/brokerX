高頻陷阱卡

⚡ 陷阱 01｜典權人 vs 出典人
地價稅、房屋稅、契稅的設典納稅義務人是誰？
→ 地價稅、房屋稅、契稅皆為典權人；唯獨土增稅設典預繳是出典人，回贖時無息退還。「地價稅納稅人是出典人」是錯誤選項。
⚡ 陷阱 02｜買方 vs 賣方
買賣中契稅與土增稅，誰納稅？
→ 契稅＝買受人；土增稅＝原所有權人（賣方）。約定買方負擔土增稅契約有效，但法定納稅義務人不變。
⚡ 陷阱 03｜累進級距
地價稅超過累進起點地價5倍至10倍課多少？
→ 25‰（非20‰）。口訣：15→25→35→45→55，第一級後每級 +10。
⚡ 陷阱 04｜6‰ 不是 10‰
公共設施保留地保留期間仍為建築使用，地價稅稅率？
→ 6‰，不累進（土稅法§19）。未作任何使用且與使用中土地隔離＝免徵。官方答案以 6‰ 為準，勿記成 10‰。
⚡ 陷阱 05｜免徵 vs 不課徵
繼承、配偶贈與，土增稅怎麼處理？
→ 繼承＝免徵；配偶間贈與＝不課徵（須申請），再移轉時以第一次贈與前的原規定地價或前次移轉現值為原地價。
⚡ 陷阱 06｜契稅稅基
契稅以什麼價格為課稅基礎？
→ 評價委員會評定的標準價格，不是市價、不是實價登錄。
★標購／領買公產、法院拍賣不免徵契稅。
⚡ 陷阱 07｜戶籍範圍不同
土增稅自用住宅 vs 房地合一自住，戶籍人？
→ 土增稅（土稅法§34）：所有權人、配偶、直系親屬。房地合一自住：個人、配偶、未成年子女（非直系親屬，107-25）。
⚡ 陷阱 08｜新舊制稅率
房地合一持有超過10年稅率？
→ 現行 2.0（110.7.1 起）15%；2年內45%、2–5年35%、5–10年20%。106-31 為舊制，勿套用。
⚡ 陷阱 09｜房屋稅減免分類
平民住宅、合法工廠屬免徵還是減半？
→ 減半（§15 Ⅱ）。司法保護事業、私校辦公、農會公糧倉庫屬免徵（§15 Ⅰ）。分類放錯是 100-10、104-39/40 等題的陷阱。
⚡ 陷阱 10｜標準價格評定因素
「地價水準」是房屋標準價格的評定因素嗎？
→ 歷屆官方答案：評定因素為建造材料、耐用年數及折舊、街道村里地段調整率，「地價水準」為干擾。⚠ 全國法規資料庫現行§11：建造材料種類等級、耐用年數及折舊標準、所在街道村里商業交通情形、房屋供求概況，並比較實價登錄交易價格減除土地價格部分。以考試年度答案為準，知道現行差異。

⚡ 陷阱 01｜抵價地三個比例
抵價地總面積比例？
→ 原則 50%；特殊經核准不得少於 40%；曾辦農地重劃者不得少於 45%（§39）。

徵收補償加成最高40%，適用誰？

⚡ 陷阱 03｜十項負擔用地
下列何者不屬重劃共同負擔十項用地？

⚡ 陷阱 04｜抵價地原地價
領回抵價地第一次移轉，原地價？
→ 原所有權人實際領回抵價地之地價；不是被徵收當期公告土地現值，也不是抵付補償地價總額。
⚡ 陷阱 05｜權利義務終止時點
被徵收人權利義務何時終止？
→ 一般徵收＝補償費發給完竣時。領抵價地：筆記／舊官方答案＝抵價地點交接管時；⚠ 現行§40＝接到核定發給抵價地通知時。題幹年度與選項並列時，依年度判斷。
⚡ 陷阱 06｜先行使用
公共安全急需得先行使用的事業？
→ 僅國防、交通、水利；社福、環保、衛生、平價住宅不在。
⚡ 陷阱 07｜兩個期間數字
重劃禁限期間與標租上限？
→ 重劃禁止期間不超過1年6個月；區段徵收標租期限不得逾99年。
⚡ 陷阱 08｜公聽會 vs 聽證
特定農業區農牧用地徵收須聽證？
→ 一般徵收案僅須公聽會；經行政院核定重大建設須徵收特定農業區且有爭議→依行政程序法聽證。
⚡ 陷阱 09｜協議價購無優購權
協議價購時，他法律規定的優先購買權適用嗎？
→ 不適用（土徵§11，筆記）；協議價格以市場正常交易價格為基準，非公告現值。

抵押權人對基地或房屋出賣有優先購買權嗎？

哪一條優先購買權有物權效力？
