第一篇　不動產經紀業管理條例
A1總則：名詞定義與主管機關
定義

主管機關：中央內政部／直轄市地政處／縣市政府

易混淆比較

成屋：領有使用執照，或實施建管前建造完成之建築物

預售屋：領有建造執照尚未建造完成，以將來完成之建築物為交易標的

仲介業務：買賣互易租賃之居間或代理

代銷業務：受起造人或建築業委託，企劃並代理銷售

陷阱
差價定義
高頻陷阱

「差價」＝實際買賣交易價格與委託銷售價格之差額，不是與市場行情價的差額！

A2經紀業之設立、營業保證金與營業處所
口訣

申請許可 → 辦理公司或商業登記 → 加入登記所在地同業公會 → 6個月內開始營業（得展延一次，以3個月為限）

陷阱
國外業務
高頻陷阱

經營國外不動產仲介或代銷業務者，應以「公司」型態組織辦理登記，商號不可！

法條要件

不得申請經營經紀業事由：詐欺背信侵占罪徒刑1年以上未滿3年／受感訓處分未滿3年／撤銷廢止許可未滿5年／廢止經紀人員證書未滿5年

定義

營業保證金由全國聯合會統一設置基金專戶管理；經紀業代表人數不得超過委員總數五分之二

退還條件：解散歇業/組織存續已無業務，核准註銷營業滿1年後2年內請求退還（孳息不退還）

陷阱
配置數字
高頻陷阱數字

非常態處所銷售額達6億以上至少專業經紀人1人
經紀營業員每逾20名增設經紀人1人

項目經紀人經紀營業員

兼職限制

經紀人員原則應專任一經紀業，但經所屬經紀業同意為他經紀業執行業務者，不在此限——並非絕對禁止兼職！

A4業務及責任（本科最核心高頻章節）
法條要件

廣告與銷售三前提：①須先簽委託契約書方得刊登廣告及銷售②內容應與事實相符並註明經紀業名稱③不符者負損害賠償責任

口訣

應由經紀人簽章六類文件：①委託契約書②要約書③定金收據④廣告稿⑤不動產說明書⑥租賃買賣契約書

陷阱
代銷例外
高頻陷阱

第①②款（委託契約書、要約書）於經營「代銷業務」者不適用！代銷業是建商委託，相對人是社會大眾買方，無「委託契約書」概念

極高頻
解說流程
★極高頻口訣

不動產說明書解說流程：製作 → 委託人先簽章確認 → 經紀人向相對人解說 → 締約時交付相對人並簽章 → 視為契約之一部分

陷阱
說明書≠確認書
高頻陷阱

不動產說明書（經紀人製作，委託人與相對人皆需簽章，視為契約一部分）≠ 建物現況確認書（成屋契約附件一，賣方自填現況，不得替代說明書內容！）

定義

雙方代理六項義務：①公平提供類似交易價格②公平提供契約說明③提供必要資訊④告知應查知瑕疵⑤協助必要檢查⑥其他主管機關規定

法條要件

申報登錄期限：仲介（租賃案件）簽約起30日內；代銷（委託契約）簽訂變更終止起30日內備查；代銷（買賣契約）簽約起30日內登錄

陷阱
加倍返還
高頻陷阱

不得收取差價或其他報酬，違反者：已收取部分應加計利息後加倍返還支付人

A5獎懲：行政罰與刑罰對照表
法條要件

經紀業最常見罰鍰級距（第7Ⅵ/11/17/19Ⅰ/21/22Ⅰ）：NT$6萬以上30萬以下

易混淆比較

申誡：第16兼業/22Ⅰ簽章/23解說/25保密

6個月以上3年以下停止執行業務：第19Ⅰ收取差價或報酬

陷阱
累計後果
高頻陷阱

申誡累計3次 → 另予6個月以上3年以下停止執行業務；停止執行業務累計達5年以上 → 廢止經紀人員證書

陷阱
先罰後刑
高頻陷阱

非經紀業違法經營：①先禁止營業＋罰鍰（NT$10萬-30萬）②經禁止後仍繼續營業才構成刑責（1年以下徒刑或併科10萬-30萬罰金）——並非一犯就有刑責！

第二篇　不動產經紀業管理條例施行細則
B1重要施行細則補充規定
法條要件

申請文件不合規定：通知15日內補正，屆期未補正駁回

名稱/所在地/組織型態變更：應於30日內書面申請備查

遷出管轄區域：遷出後30日內申請遷入備查

分設營業處所：設立後30日內書面申請備查

定義

應永久保存之簿冊：經紀業管理登記簿、外縣市營業處所管理登記簿、經紀人名簿、經紀營業員名簿、經紀業專冊

法條要件

經紀人換發證書：應於證書效期屆滿前6個月內申請；換發後效期自原證書屆滿次日起算4年

第三篇　不動產說明書應記載及不得記載事項（115.1.13最新修正版）

口訣

標示權利→所有權人→交易權利種類→管理使用情況→使用管制→重要交易條件→其他重要事項

C2成屋應記載事項架構
定義

建物型態三分類：一般建物（獨棟/連棟/雙併，無共有部分）／區分所有建物（公寓/透天/店面/大樓/華廈/套房）／其他特殊建物（工廠/廠辦/農舍/倉庫）

115新增
建築能效
★115年新增

新增第6目「建築能效情形」：有無取得建築能效標示？若有應敘明等級、核發日期及證書效期（配合近零碳建築政策）

C3預售屋應記載事項架構
定義

較成屋多：建照字號、出售面積占比、共有部分分配比例、主要建材廠牌、工程進度（開工/取照/通知交屋/保固期限）、規約草約7項內容

陷阱
僅預售屋適用
★115年陷阱

氯離子檢測用語更新：舊「混凝土氯離子含量檢測報告＋無放射性污染證明」→新「施工中建築物新拌混凝土氯離子含量檢測報告單＋無輻射污染證明」——僅見於預售屋，成屋章節未同步修正！

C4不得記載事項（土地、成屋、預售屋共通）
法條要件

①不得載「僅供參考」②不得載「繳回說明書」③不得用受益/銷售/使用面積等替代詞④預售屋不得載未領照夾層⑤不得以現況確認書替代說明書⑥不得載房價有上漲空間

C5115年修正總結：三大新增重點
115修正
三大重點
★最新考點

第四篇　三種定型化契約應記載及不得記載事項
D1成屋買賣定型化契約
定義

契約審閱期：至少5日

法條要件

交屋遲延違約金：賣方逾期交屋，買方得請求每日按已付價款萬分之二單利計算之損害賠償

高頻
違約罰則
★核心高頻

賣方違約：全部退還已付價款＋每日萬分之二單利＋同額違約金，但不超過總價15%

買方違約（逾期5日未付款）：賣方沒收已付價款充違約金，不超過總價15%

法條要件

不得記載超過民法第205條週年16%利率之利息

D2預售屋買賣定型化契約
定義

契約審閱期：至少5日；履約擔保五選一：不動產開發信託／價金返還保證／價金信託／同業連帶擔保／公會連帶保證協定

陷阱
誤差找補
高頻陷阱

面積誤差找補：不足部分賣方全部找補；超過部分買方最多找補2%；誤差超過3%買方得解約

法條要件

保固期限：結構部分（基礎/樑柱/承重牆/樓地板/屋頂/樓梯/擋土牆）15年；固定建材設備（門窗/粉刷/地磚）1年

陷阱
方向相反
高頻陷阱

與成屋契約「不超過15%」相反！預售屋違約金「不得低於15%」（賣方違約）；買方違約沒收「最高不得超過15%」

D3不動產委託銷售定型化契約（含要約書）
陷阱
審閱期不同
高頻陷阱

契約審閱期：不得少於3日（注意：與成屋/預售屋「至少5日」不同！）

法條要件

受託人六大義務：①善良管理人注意②簽約前提供近3個月成交行情③市調廣告費自行負擔④說明書指派經紀人簽章⑤要約書24小時內轉交⑥定金24小時內送交

陷阱
禁收斡旋金
★高頻陷阱

不得約定在契約成立前，受託人得向消費者收取斡旋金、訂金或其他任何名目之費用——實務常見但定型化契約明文禁止事先收取！

第五篇　公寓大廈管理條例
E1總則與名詞定義
定義

主管機關：中央內政部／直轄市政府／縣市政府

四種部分：專有部分／共用部分／約定專用部分／約定共用部分

易混淆比較

住戶：區權人/承租人/經同意使用人/取得停車空間所有權者

管理委員會：執行區權會決議的組織

管理負責人：未成立管委會時推選之住戶1人

E2住戶之權利義務
★高頻

不得約定專用之共用部分：①本身所占地面②走廊樓梯通道巷道防火巷弄③基礎主要樑柱承重牆樓地板屋頂④違反法令限制者⑤其他生活不可或缺者

法條要件

外牆變更構造違反者：管理負責人應制止，逾1個月未回復原狀，管委會得代為回復，費用由該住戶負擔

高頻
遷離拍賣流程
★高頻流程口訣

強制遷離/拍賣：積欠1%或受罰仍不改善 → 3個月內未改善依區權會決議訴請強制遷離 → 拒絕出讓判決確定3個月內未移轉 → 聲請法院拍賣 → 受償順序與第一順位抵押權同

E3管理組織
陷阱
決議門檻
★高頻決議門檻
類型出席同意
一般決議2/3以上出席3/4以上
流會重新召集3人並1/5以上出席過半數（7日內得提反對）
陷阱
表決權限制
高頻陷阱

單一人表決權限制：任一區權人占全部1/5以上者，超過部分不予計算，防止大戶壟斷

陷阱
連任次數
高頻陷阱

主委/管理負責人/財務監察委員：連選得連任1次；其餘一般管理委員：連任無次數限制！

E4規約
★高頻

非經載明於規約不生效力七項：約定專用共用範圍／使用收益特約／禁養動物特約／違反義務處理方式／財務監督規定／決議額數特約／糾紛協調程序

定義

規約範本：由中央主管機關定之，性質為參考性非強制套用；施行前已取得建照者，訂定規約前以規約範本視為規約

E5罰則
法條要件

第47條（召集義務/棄置垃圾）：3千-1萬5千

第49條（外觀變更/未投保/未繳基金）：4萬-20萬

第49-1條（未成立管委會）：每專有部分4萬-20萬

陷阱
刑責限制
高頻陷阱

刑事責任僅限「供營業使用事實之住戶」違反第49條第3、4款致人於死或重傷：致死1-7年徒刑；致重傷6個月-5年徒刑

E6附則重點
法條要件

起造人應於管委會成立或負責人推選後7日內會同檢測水電機械消防管線後移交

陷阱
重建同意
高頻陷阱

重建原則：應經全體區權人及基地所有權人/地上權人/典權人同意；例外（都更/嚴重毀損/災變）不在此限，可依區權會決議重建

1000萬以下千分之20

F2規約範本之法律性質分類
高頻
四層級分類
★高頻四層級口訣

①沒寫就無效（條例23條7項）②寫了也無效（條例7條不得約定專用）③僅得變更（須先有規定，如決議額數）④可以變更（任意性規定，如外牆限制/任期）

第七篇　公平交易法與不動產經紀業廣告處理原則
G1公平交易法重要條文
定義

第21條：事業不得在商品或廣告上，對足以影響交易決定之事項，為虛偽不實或引人錯誤之表示或表徵

★高頻連帶責任

廣告代理業／廣告媒體業／廣告薦證者：明知或可得而知仍製作傳播薦證 → 與廣告主負連帶賠償責任（薦證者非知名人士僅報酬10倍範圍內負責）

法條要件

故意行為法院得酌定不超過已證明損害額3倍之賠償；違反第21條：NT$5萬-2500萬罰鍰，屆期不改正按次處10萬-5000萬

G2不動產經紀業廣告查核分工原則
極高頻
五分工
★極高頻五分工口訣
廣告類型處理機關
經紀業自身廣告主管機關（管理條例）
涉企業形象/行銷策略虛偽不實公平交易委員會
加盟未標明加盟字樣主管機關
建商與經紀業共同具名廣告主公平交易委員會
無法劃分內政部與公平會協調
陷阱
建商自售
高頻陷阱

若建商自行銷售（非委託經紀業），廣告不實非屬管理條例範疇，應回歸公平交易法處理！

法條要件

不實廣告認定七項：坐落地點不符／面積不符登記／格局與事實不符／圖說文字不符／建材不符／公設交通表徵不符／停車位廣告與施工圖不符

第八篇　消費者保護法
H1定型化契約規範
★核心高頻

第17條：中央主管機關得選擇特定行業，擬訂應記載/不得記載事項，報請行政院核定後公告——此即三大定型化契約之法律授權來源

陷阱

高頻陷阱
