🏷 標＝標的資料：標示・權利・用途・管制 📊 因＝因素資料：一般・區域・個別因素 🔁 比＝比較實例：交易・收益・成本資料

技術規則 §14
兼採二種以上原則
比較標的整理 §23 排除13款情形 ▼ §25 單項調整率>15% 或 總調整率>30% → 排除 §26 試算價格差距率≥20% → 排除最高/最低
§23 比較標的排除13款（背口訣：價正案因契位面時空用役限他）
① 成交價格有明顯瑕疵
② 非屬正常市場
③ 案例已逾5年（建物3年）
④ 影響因素差距過大
⑤ 契約特殊
⑥ 非整筆交易
⑦ 面積差距過大
⑧ 時間調整超3年
⑨ 供需圈不同
⑩ 用途或管制不相近
⑪ 役權設定
⑫ 受法令限制
⑬ 其他不宜
⚠ 考題常問「何者可作為比較標的」→ 排除13款即可推導
📏 §25/§26 白話記憶
§25 個別項調整率：某比較案例「路寬」比標的窄，要調整 +18% → 超過15%上限 → 整筆排除
 → 口訣：「單項超過一個巴掌（15%），砍掉不用」
§25 合計調整率：同一案例各項加總後 = 32% → 超過30%上限 → 排除
 → 口訣：「東調西調超過三成，已失代表性」
§26 差距排除：三件試算：A=100萬、B=123萬、C=111萬
 差距率 = (123–100)÷111 = 20.7% ≥ 20% → 排除最高B（或最低A？優先排外離最大者）
 → 口訣：「三件中最高最低差超過兩成，先刷最離群那個」
例外：情況特殊不能採二種以上方法 → 於報告書敘明理由

技術規則 §15 前段
四大方法
比較法 → 比較價格 成本法 → 成本價格 收益法 → 收益價格 土地開發分析法 → V值
比較法調整順序（§21）：情況調整 → 價格日期調整 → 區域因素調整 → 個別因素調整（口訣：情・價・區・個）
§70 關鍵定義（宗地通則）
正常價格：公開市場、無特殊動機之合理價格
限定價格：條件或對象受限下之特殊價格
特定價格：特殊條件（投資、清算）下的價格
特殊價格：公共使用或非市場流通之不動產
比較價格：由比較法推算所得
收益價格：由收益法推算所得
成本價格：由成本法推算所得
勘估標的價格：最終決定之完整估價結果
