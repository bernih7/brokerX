## 2026-10-31｜經紀法規 v601：106-33 題幹依官方試題更正；sync 腳本改白名單制；診斷出 58 頁深色被寫死的 bug

### 一、106-33 題幹更正（v597 的待辦結案）
使用者提供考選部官方試題：題幹是「其為下列何者**非不得為**約定專用部分？」，
站上原記「何者**不得作為**約定專用部分」——**漏了一個「非」字**，變成雙重否定被寫成單純否定，
難怪方向和官方答案 C 相反。更正後完全合理：問的是「哪一個可以」，
而 A（本身所占地面，§7①）、B（巷道防火巷弄，§7②）、D（主要梁柱構造，§7③）三個都在禁止清單裡，
只有 C（**非**連通數個專有部分之樓梯或走廊）不在五款之內，所以 C 是答案。
四個選項的解析全部重寫，A／B／D 明確指出各自落在 §7 哪一款，正解解析點明
「關鍵字是『連通數個專有部分』——有連通才禁止」與「『非不得』是雙重否定，先讀成『哪一個可以』」。

### 三、⚠️ 深色模式：不是沒做，是 58 頁被開機腳本寫死（跨科）
v597 記「12 支刷題頁不吃深色模式」，使用者要求先出 demo。做 demo 時才查出**真正原因是 bug**：
- 深色色票本來就寫好了（`:root[data-theme="dark"]` 與 `@media (prefers-color-scheme:dark)` 兩段都有），
  手動按右上角「深色」鈕也正常。
- 壞的是 `<head>` 的開機腳本：`setAttribute("data-theme", s || "light")`
  ——沒存過偏好時**把 `data-theme` 寫死成 `"light"`**。
  而深色的 media query 條件是 `:root:not([data-theme="light"])`，被這行寫死後
  **系統設成深色也被擋掉**。另有 14 頁的 `setTh(lsG('bx-theme')||'light')` 同一個毛病。
- **影響範圍：58 頁**——經紀法規 25、民法 32、土地法 1；估價 0。
  站上另外 110 頁沒有寫死，會正常跟隨系統 → **這是四科不一致，不是缺功能**。
  ⚠️ **這個 58 頁是低估的**：只掃了雙引號那一種寫法。v607 用 regex 全面掃是 **90 頁、九種寫法**。
- 已出 artifact demo 給使用者選三個方案：A 跟隨系統（建議，改兩行、與其他 110 頁一致）／
  B 維持現狀永遠淺色／C 跟隨系統但第一次提示一次。demo 內並排了真實題卡的淺／深對照。
  → **使用者選 A、四科一起改；v607 已全部完成。**
