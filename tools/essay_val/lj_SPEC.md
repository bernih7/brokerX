# 估價申論卡「邏輯拆解」資料撰寫規格（沿用民法 lj_SPEC，估價版）

來源：KB《備考_申論頁標準作法_跨科套用指南_v3》第十一節；民法 `tools/essay_civ/lj_SPEC.md`。
頁面：`不動產估價概要_申論題實戰範文.html`（唯一正本；指揮中心申論分頁只是導覽，不另維護一份）。
資料：`lj_data.json`（陣列，k＝卡片 id，如 e113-1、pred-4）；產生器 `gen_lj.py`（可重複執行）；檢查 `check_lj.py`。

## 每題物件
```json
{"k":"e113-1","kind":"explain|calc|case",
 "subs":[{"q":"子題問句（題目問幾件事就幾個）","pre":"（選填）承接上一子題的一句",
   "steps":[{"ask":"先問自己的一句","lawh":"條號＋名稱（計算題＝方法／公式標題）","law":"條文白話／公式",
             "facth":"右欄小標","fact":"適用情形／本題代入","res":"小結","key":"地圖用短語≤22字","link":"為什麼接下一步"}],
   "ans":"子題答案句，關鍵結論 **粗體**"}],
 "checks":[{"t":"law|fact|ans","txt":"採分點","sub":1,"hot":false}],   // 5～9 點；hot＝對應常見失分點（2～3點）
 "kw":["得分關鍵詞（必須逐字出現在該卡內）"],
 "mnem":"（選填）口訣，箭頭串推理順序"}
```
## kind 與欄位意義
- explain（說明題，無人物事實）：步驟＝定義（技術規則條號）→ 適用情形 → 限制或注意事項。右欄小標用「適用情形／限制」。
- calc（計算題）：步驟＝選方法（條號）→ 公式 → 代入本題數字 → 小結（含單位、四捨五入）。② 對照欄＝「公式｜代入」。
- case（有人物事實的分析題）：同民法：條文｜本題。
## 規則
1. 只用該題範文（速答版、完整四段式）裡已有的法律內容；不得新增條號、學說、數字（純算術中間步驟可以，須驗算）。覺得缺就寫進 flags。
2. 每個子題都有 ans；ans 直接回答子題問句。
3. 拆解裡出現的每個 §條號 都必須出現在該卡範文；kw 必須逐字出現在該卡。
4. 判決、決議、函釋不得憑記憶；範文沒有就不寫。
5. 繁體中文、白話、短句；人物沿用題目代號；不用 emoji。
