### 深淺色（2026-10-31 經紀法規 v601 確立、v607 四科 90 頁全站套用）
- 開機腳本**不要在沒存過偏好時寫 `data-theme`**。寫死 `"light"` 會讓深色的
  `:root:not([data-theme="light"])` media query 失效，系統深色也被擋掉。
- 正確寫法：有存過偏好才 `setAttribute`，沒存過就不寫，交給 `prefers-color-scheme`。
- **切換鈕與按鈕文字也要「有屬性看屬性，沒屬性看系統」**
  （`getAttribute('data-theme')||((matchMedia('(prefers-color-scheme:dark)').matches)?'dark':'light')`），
  否則系統深色時第一次按鈕是空按（它以為現在是 light，切到 dark 畫面沒變）。
- 切換鈕按下後才寫入 localStorage（`bx-theme`），之後以使用者的選擇為準。**鍵名不得改**。
- **`<html>` 標籤不要寫 `data-theme`**（估價備考指揮中心曾寫死 light，JS 怎麼改都沒用）。
- **深色色票一定要有 `@media (prefers-color-scheme:dark)` 版本**，不能只寫 `[data-theme=dark]`，
  否則拿掉屬性後會變全白（民法兩頁曾如此）。補的時候把既有規則**原值**鏡像，不要調色。
- 掃這類 bug 要用 regex 涵蓋引號、空白、變數名的變體：v601 只掃雙引號版報 58 頁，
  v607 全面掃是 **90 頁、九種寫法**。
- 寫檔前先做安全前置檢查（裸 `:root` 裡有任何 `--xxx:`、頁內有 prefers-color-scheme），
  **不要綁特定變數名**（各科 token 名不同：`--bg`／`--paper`／`--cp-card`…）。

### 閱讀／速查頁版型（2026-10-15 土地法使用者再次要求）
- 閱讀、速查、整理類頁面一律：各組預設收合＋「全部展開／全部收合」鈕；搜尋時自動展開；期間、數字用彩色粗體加底色；陷阱卡彩色左邊框；口訣用暖色底框。新頁、舊頁改版皆照此。
- **標色統一色票（2026-10-15）**：關鍵詞＝紅粗體（無底色）、數字／稅率／期限＝金底、口訣＝綠底、考試陷阱＝紅底；條號用棕粗體。不得自創新色塊組合；一段文字中標色密度宜低。申論／長答案：分段色塊（定義綠／法條藍／涵攝金／結論紅）＋段內小格。
- **改色後一定跑 `tools/theme/contrast_scan.js` dark／light**（v615）：深色覆寫兩份式、不用頁面沒定義的變數、強調色底上的字不寫死 #fff。
- **不要用一大塊紅色底色排列表／清單**（2026-10-31 使用者：「很不好看、不清楚」）：列表用中性底＋細框，只在條號或小標籤上色。
- 比較表（多欄對照表）不要做成一大張表：每一列拆成一張彩色收合卡，列內各欄為彩色小卡（手機單欄、桌面多欄並排）。見《速查三表》②③。

### 申論卡版面（2026-10-25 經紀法規確立，四科通用）
- **摘要列壓成一行**：級別膠囊（★★★ 必考）與編號膠囊同列，**關鍵詞 chips 收合時隱藏、展開後才出現**。收合卡高度應在 100px 上下。
- **不要左側色條**（v3 標準第三節）：篇別改用標題前小圓點；預測題與補習班模擬卷用**整圈虛線框**區分。
- **legend 最多兩行**，且每次改分頁名稱時要回頭檢查 legend 是否還在寫舊名稱。
- **重複出現在每張卡的說明文字**（例：排法說明）收進「？」開關，狀態記 localStorage。
- 進度列：數字一列、按鈕一列；至少要有「只看未讀」與「挑下一題未讀」。

### 刷題解析寫法（2026-10-30 經紀法規 v597 確立，四科通用）
- **強調只能用「」與『』**（第二層用『』）。`<b>` 與 `**` 在兩個渲染端都會原樣印出來。唯一吃 HTML 的是 `oos` 欄。
- **非正解的解析要寫出正確值**，不能只寫「數字錯誤」「金額級距不符」；而且要指名那個干擾數字其實是哪一條哪一款的真實級距。
- **不要斷言「法條並無此規定／虛構機制」**，除非已回逐字條文確認。這類斷言錯了會讓相似的正敘述題全數答錯。
- **出題年舊制與現行法不同時**，把現行法寫在「錯的那幾個選項」上，並在 ref 標 ⚠️。
- **`law` 欄是給人點進去跳條文用的**，法律名稱掛錯比不填更糟（同號異法最常見）。
- **同步腳本要先 dry-run**（v601）：頁面副本可能做過人工清理（排序箭頭、引號間距），
  全量從資料源覆寫會把清理成果沖掉。題幹／選項的覆寫用白名單，解析與 ref 才全量同步。
- **「非技術規則明文／非條文用語」不能當錯選項的唯一理由**（估價 v604）：正解若也是教材用語，這個理由會連正解一起排除；要寫內容差異。
- **計算題錯選項寫出誤算式**，反推不出就寫「無法由題幹常見誤算得到」＋正確值（估價 v604）。
- **自編題不寫「題庫答案／以官方公告為準」**；答案與條文不符就改題（估價 v604）。
