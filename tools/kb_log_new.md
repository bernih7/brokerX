## 2026-10-28｜估價 v555：三支整理頁內嵌「可作答」考古題面板（移植經紀法規 v553）；**查出跨科題號同號不同題的坑**

### 一、新檔 `bxv-topic-qa.js`（19 KB）
由 `tools/mk_bxv_topicqa.py` 從 `bxj-topic-q.js` **程式化產生**，不是手抄，上游改了重跑即可。
估價既有的 `bxv-topic-q.js`（只讀版，四大方法比較表／特殊標的總整理在用）**完全沒動**。

移植時四個實質差異（不是改名字而已，其他科移植時同樣要注意）：
1. **紀錄 id 不同**。經紀法規是「章-年-題號」；估價 `BXREP.qid` 是 `章-year-id`，
   year 是中文「99年第2題」、id 是「VA1_99_2」。實測寫出 `C1-114年第18題-VC1_114_18`，
   與刷題頁、解析版練習完全一致。⚠️ 傳給 BXREP 的物件**不可以帶 num**，帶了 qid 會變成 章-年-num。
2. **`r.c` 存的是選項索引不是字母**。估價解析版練習傳 idx，面板也要傳 idx，
   回頭渲染「你選的」時再把 idx 轉回字母。
3. **要雙寫章節頁存檔**。估價有 16 支刷題章節頁，各自用 `bxv-st:<ANS[ch]>_answers`／`_errortags`。
   不雙寫的話，在面板答過的題到刷題頁會顯示「還沒做」。「再作答一次」也要一併清掉章節頁那筆。
   （經紀法規沒有這個問題，它沒有各章獨立存檔。）
4. 估價題庫**沒有「本題相關法條」欄位**，所以法條逐字區自動不出現。
另：CSS 變數一律補 fallback——估價各頁 token 名稱不一致（`--fg`/`--ink`、`--primary`/`--pri`）。

### 二、掛上三頁（`tools/add_bxv_tq.py`，可重複執行）
- **營造施工費四法 `#s4`**：14 題（C1 營造或施工費）。原本寫「作答請至刷題 C1」，已改。

掛法是在檔尾插 mount script，用 JS 依錨點建 div，再載入面板本體——不用字串切位置。
**mount 一定要排在面板本體前面**，否則面板開機時還看不到那個 div。

### 三、⚠️ 本輪最重要的發現：跨科題號同號不同題
《地價調查估計規則專欄》第九節寫的 **102-8、103-18、103-6、101-9 是「土地法科」的題號**
（頁面上有標明是跨科連結，出自土地徵收條例）。但**估價題庫裡同一個號碼是完全不同的題**：
102-8＝DCF 證券化、103-18＝收益法敘述、103-6＝路沖屬何種因素、101-9＝勘估標的範圍。

→ **自動把題號變連結／自動配題時，跨科引用的題號會被連到本科完全不相干的題上。**
這四個沒有掛進面板。**土地法、經紀法規做同樣的事之前務必先查這一點**：
先找出頁面上標「跨科」「土地法科」「民法科」等字樣附近的題號，排除掉再自動處理。
（⚠️ 經紀法規已於 v556 查過 8 支頁，沒有跨科題號。）

- 閱讀、速查、整理類頁面一律：各組預設收合＋「全部展開／全部收合」鈕；搜尋時自動展開；期間、數字用彩色粗體加底色；陷阱卡彩色左邊框；口訣用暖色底框。新頁、舊頁改版皆照此。
- **標色統一色票（2026-10-15）**：關鍵詞＝紅粗體（無底色）、數字／稅率／期限＝金底、口訣＝綠底、考試陷阱＝紅底；條號用棕粗體。不得自創新色塊組合；一段文字中標色密度宜低。申論／長答案：分段色塊（定義綠／法條藍／涵攝金／結論紅）＋段內小格。
- 比較表（多欄對照表）不要做成一大張表：每一列拆成一張彩色收合卡，列內各欄為彩色小卡（手機單欄、桌面多欄並排）。見《速查三表》②③。

### 申論卡版面（2026-10-25 經紀法規確立，四科通用）
- **摘要列壓成一行**：級別膠囊（★★★ 必考）與編號膠囊同列，**關鍵詞 chips 收合時隱藏、展開後才出現**。收合卡高度應在 100px 上下。
- **不要左側色條**（v3 標準第三節）：篇別改用標題前小圓點；預測題與補習班模擬卷用**整圈虛線框**區分。
- **legend 最多兩行**，且每次改分頁名稱時要回頭檢查 legend 是否還在寫舊名稱。
- **重複出現在每張卡的說明文字**（例：排法說明）收進「？」開關，狀態記 localStorage。
- 進度列：數字一列、按鈕一列；至少要有「只看未讀」與「挑下一題未讀」。
