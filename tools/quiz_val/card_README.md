# 任務：替估價刷題每個「錯誤選項」寫一張「更正卡」

使用者選錯某個選項時，畫面會出現一張小卡，一眼看完「錯在哪、正確的是什麼」。你要為每題每個**非答案選項**寫這張卡的內容。

輸入 gN_in2.json：每題 {id, q, opts[4], exps[4], correct, hl}。exps[i] 是選項 i 的解析；hl 是先前標的「選項錯字 e／解析正確片段 f」（可參考，不必照用）。**官方答案 correct 不得質疑或改動。**
條文逐字檔在 ../law/（技術規則 §1～§133、地價調查估計規則、土地徵收補償市價查估辦法、市地重劃實施辦法 §19～§20、全聯會公報）。

## 卡片格式
每個非答案選項 i 輸出 rows：2～3 列，每列 [標籤, 文字]。標籤只能用下列幾種，依題型選：

**(1) 選項 i 本身是錯誤敘述（「何者正確」題的錯選項、分類／名稱題選錯的名詞）**
- ["錯在", 選項裡錯的部分（簡短，盡量用選項原字，可加「」）]
- ["應該是", 正確說法（可附條號，如「（§75）」）]
例：99-37 選 D → [["錯在","按「法定容積」面積計算"],["應該是","按「開發或建築後可銷售之土地或建物面積」計算（§75）"]]
例：名稱題 → [["錯在","「勘察日期」是赴現場調查之日期"],["應該是","題述的基準日期稱為「價格日期」（§2⑦）"]]

**(2) 選項 i 本身是正確敘述（「何者錯誤／最不適宜／非屬／不包含」題，你選了一個對的）**
- ["你的選項", 為什麼它是對的、所以不是答案（一句）]
- ["答案錯在", 答案選項錯的部分]
- ["因為", 正確說法]
例：101-6 選 C → [["你的選項","有行無市＝價格隨市場變動，屬變動原則，是對的敘述"],["答案錯在","B「老舊公寓飆漲係基於均衡原則」"],["因為","飆漲是市場供需或區域發展所致，與均衡原則（生產要素最適配置）無關"]]
（「下列何者非屬 X」題：你選的屬於 X → 你的選項 寫「○○屬於 X」；答案錯在 寫答案那項；因為 寫它為何不屬於 X。）

**(3) 計算題**
- ["你算的", 選項數字＝它的誤算式（若反推不出就寫「400：無法由題幹常見誤算得到」）]
- ["正確算法", 完整正確算式＝答案值]
例：114-3 選 400 → [["你算的","400＝2,000÷50×10，漏扣殘價率 10%"],["正確算法","2,000×(1－10%)÷50×10＝360 萬"]]

## 硬規則（違反就是錯）
1. **只能寫題目、選項、解析、條文逐字檔裡有依據的內容。**不得憑記憶補條文。條號只能用該題 exps 裡出現過的，或你在 ../law/ 逐字找到的。
2. 若用了 exps 沒有、而是你從 ../law/ 找到的條文內容，在該選項加 "src": "§N：『逐字片段』"（片段必須逐字出現在 law 檔，8～40 字）。
3. 計算題所有數字都要用 python 重算確認；算式結果必須等於官方答案選項的值。
4. 每列文字 ≤ 45 字，口語白話、不要「本選項」「此敘述」這類套話。強調只用「」，不得用 <b> 或 **。
5. 解析本身若與官方答案衝突、或題目有疑義（一律給分、OCR 疑誤），該題全部給 null 並列入回報。
6. 答案選項 correct 那格給 null。

## 輸出
gN_card.json：{"<id>": [opt0, opt1, opt2, opt3]}，每格 null 或 {"rows":[[標籤,文字],...], "src"?: "..."}。全部題目都要有鍵。
寫完跑 `python3 check2.py gN` 到 0 錯。只回報：題數、卡片數、null 題號與原因、用了 src 的筆數、你沒把握的題號（≤10）。不要改任何網站檔案。
