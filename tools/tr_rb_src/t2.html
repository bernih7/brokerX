§18・§21比較法六步、試算價格逐字核對

  1. §18Ⅰ比較法指以比較標的價格為基礎，經比較、分析及調整等，以推算勘估標的價格之方法
  2. §18Ⅱ依前項方法所求得之價格為比較價格
§21Ⅰ 程序（六步）
  1. 一蒐集並查證比較標的相關資料
  2. 二選擇與勘估標的條件相同或相似之比較標的
  3. 三對比較標的價格進行情況調整及價格日期調整
  4. 四比較、分析勘估標的及比較標的間之區域因素及個別因素之差異，並求取其調整率或調整額
  5. 五計算勘估標的之試算價格
  6. 六決定勘估標的之比較價格

§21Ⅱ：第五款所稱之試算價格，指以比較標的價格經情況調整、價格日期調整、區域因素調整及個別因素調整後所獲得之價格；第⑥步再「決定」比較價格。

調整對象是比較標的的價格，目的是把它轉成「跟勘估標的同條件」的價格；不是去調勘估標的（108-20）

  2. 價格日期調整比較標的之交易日期與勘估標的之價格日期因時間之差異，致價格水準發生變動，應以適當之變動率或變動金額，將比較標的價格調整為勘估標的價格日期之價格

  4. 個別因素調整以比較標的之價格為基礎，就比較標的與勘估標的因個別因素不同所產生之價格差異，逐項進行之分析及調整

§19⑤～⑦・§24・§20怎麼調：百分率法為原則逐字核對

  1. 百分率法將影響勘估標的及比較標的價格差異之區域因素及個別因素逐項比較，並依優劣程度或高低等級所評定之差異百分率進行價格調整之方法
  2. 差額法將影響勘估標的及比較標的價格差異之區域因素及個別因素逐項比較，並依優劣程度或高低等級所評定之差額進行價格調整之方法
  3. 計量模型分析法蒐集相當數量具代表性之比較標的，透過計量模型分析，求出各主要影響價格因素與比較標的價格二者之關係式，以推算各主要影響價格因素之調整率及調整額之方法
  4. §24區域因素及個別因素差異之價格調整，以百分率法為原則，亦得以差額法調整，並應於估價報告書中敘明
§20 計量模型分析法應符合（三款）
  1. 一須蒐集應用計量模型分析關係式自變數個數五倍以上之比較標的
  2. 二採迴歸分析者，其調整後判定係數不得低於零點七
  3. 三截距項以外其他各主要影響價格因素之係數估計值同時為零之顯著機率不得大於百分之五
怎麼記

  • 評定的是差額（金額）→ 差額法；評定的是百分率 → 百分率法，名稱別互換（99-18）

§27三件以上、決定比較價格逐字核對

  1. 件數不動產估價師應採用三件以上比較標的
  2. 依據就其經前條推估檢討後之勘估標的試算價格
  3. 考量一各比較標的蒐集資料可信度
  4. 考量二各比較標的與勘估標的價格形成因素之相近程度
  5. 結果決定勘估標的之比較價格，並將比較修正內容敘明之

年度題號與選項取自站上題庫（官方答案）；§18～§27 條文已對照全文原文（知識庫《估價_技術規則_全文逐字_§1-§133_20261022》）。
