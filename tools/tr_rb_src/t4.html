§48成本法・重建成本／重置成本逐字核對

0定義
成本價格＝重建成本／重置成本−累積折舊額
  1. 成本法求取勘估標的於價格日期之重建成本或重置成本，扣減其累積折舊額或其他應扣除部分，以推算勘估標的價格之方法；所求得之價格為成本價格
  2. 原則建物估價以求取重建成本為原則
  3. 例外建物使用之材料目前已無生產或施工方法已改變者，得採重置成本替代之
  4. 重建成本使用與勘估標的相同或極類似之建材標準、設計、配置及施工品質，於價格日期重新複製建築所需之成本
  5. 重置成本與勘估標的相同效用之建物，以現代建材標準、設計及配置，於價格日期建築所需之成本

§54：得按下列方法擇一求取之。

  1. §54①直接法：就勘估標的之構成部分或全體，調查其使用材料之種別、品級、數量及所需勞力種別、時間等，並以勘估標的所在地區於價格日期之各種單價為基礎，計算其營造或施工費
  2. §54②間接法：就同一供需圈內近鄰地區或類似地區中選擇與勘估標的類似之比較標的或標準建物，經比較與勘估標的營造或施工費之條件差異並作價格調整，以求取勘估標的營造或施工費
  3. §55①淨計法：就所需要各種建築材料及人工之數量，逐一乘以價格日期當時該建築材料之單價及人工工資，並加計管理費、稅捐、資本利息及利潤
  4. §55②單位工程法：以建築細部工程之各項目單價乘以該工程施工數量，並合計之
  5. §56①工程造價比較法：按工程概算項目逐項比較勘估標的與比較標的或標準建物之差異，並依工程價格及工程數量比率進行調整
  6. §56②單位面積（或體積）比較法：以比較標的或標準建物之單位面積（或體積）營造或施工費單價為基礎，經比較並調整價格後，乘以勘估標的之面積（或體積）總數

§56Ⅱ 標準建物，指按營造或施工費標準表所營造或施工之建物。§56Ⅲ 標準表由全聯會按不同主體構造種類及地區公告；未公告前，依直轄市或縣（市）政府發布地價調查用建築改良物標準單價表為準。

§68累積折舊三條路徑逐字核對

§68Ⅰ：建物累積折舊額之計算，應視建物特性及市場動態，選擇屬於下列路徑之折舊方法：

  1. 等速折舊定額法：每年折舊額相同，累積折舊是直線
  2. 初期加速折舊定率法：曲線在直線下方，先陡後緩
  3. 初期減速折舊償債基金法：曲線在直線上方，先緩後陡

規則只寫這三條路徑；定額法／定率法／償債基金法的對應是教科書整理。

圖建物現值怎麼降（示意，C=100、s=10%、N=40）
初期減速（償債基金法）在直線上方等速（定額法）直線初期加速（定率法）在直線下方
三條路徑起點同為 C、終點同為 C·s；0 < n < N 時，現值恆為 定率法 < 定額法 < 償債基金法。示意圖，非精確數值。

§68Ⅱ：除考量物理與功能因素外，並得按個別建物之實際構成部分與使用狀態，考量經濟因素，觀察維修及整建情形，推估建物之賸餘經濟耐用年數，加計已經歷年數，求算耐用年數，並於估價報告書中敘明。

C 建物總成本－Dn 累積折舊＝建物成本價格
建物成本價格＝C×[ 1 － (1－s) × n ÷ N ]
定額法的一次算法。例：C 1,000 萬、s 5%、N 50、n 10 → 1,000×[1－0.95×10÷50]＝810 萬。n＝0 時＝C（全新）；n＝N 時＝C·s（只剩殘餘價格）。房地成本價格＝土地總成本＋建物成本價格，折舊已扣在裡面，不要再減一次。
怎麼記
收益兩型（等・債）
成本三路（等・加・減）
口訣・刷題 103-28 note（§40-1／§41 vs §68）
陷阱
  • 定額法年折舊率是對原始成本 C 算的；定率法的 r、§41 折舊提存率 d 都不是它
  • 算出的建物成本價格已扣折舊，加土地得房地成本價格時再減一次折舊是錯的

§69成本價格計算公式逐字核對

  1. 一土地價格＝土地總成本
  2. 二建物成本價格＝建物總成本－建物累積折舊額
  3. 三房地成本價格＝土地價格＋建物成本價格
2§69 房地成本價格
房地成本價格＝土地價格（土地總成本）＋建物成本價格
  1. §69Ⅱ土地價格之求取有困難者，得以比較法或收益法計算之，並於估價報告書中敘明；並需考量土地部分之廣告費、銷售費、管理費、稅捐、資本利息及利潤之合理性
  2. §69Ⅲ得考量已投入土地開發改良因時間經過造成之減損，並於土地總成本中扣除
怎麼記
（無口訣）
陷阱
  • 土地價格求取有困難者用比較法或收益法，土地開發分析法不在條文內
  • 折舊只扣建物；土地開發改良的時間減損是於土地總成本中扣除
